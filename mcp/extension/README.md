# DeepScribe for Claude Desktop

This extension connects Claude Desktop to the local DeepScribe desktop app.

DeepScribe must be running while Claude uses the extension. The server discovers DeepScribe's authenticated localhost bridge automatically, so no paths, ports, tokens or API keys need to be configured.

Available capabilities include reading and searching projects and blocks, creating and updating regular knowledge content, creating concrete follow-up tasks in Workspace Inbox, reading tasks, updating task progress, and reading files linked to blocks. Agent-created tasks start as Inbox and Unassigned; after creation, agents cannot edit their content or organization. Local attachment paths are never exposed to Claude.
